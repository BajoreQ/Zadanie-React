# Lista kontaktów (Wizytówka w React)

Projekt wykonany na podstawie kursu: *React - kurs podstaw w 2h krok po kroku!* (`Jak zacząć programować?`).

## Jak uruchomić projekt lokalnie?

1. Upewnij się, że masz zainstalowany **Node.js**.
2. Otwórz terminal w katalogu projektu i zainstaluj zależności:
   ```bash
   npm install
   ```
3. Uruchom serwer deweloperski:
   ```bash
   npm run dev
   ```
4. Otwórz wyświetlony w terminalu adres (zazwyczaj `http://localhost:5173`).
